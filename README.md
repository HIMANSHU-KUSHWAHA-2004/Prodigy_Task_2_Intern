<h1 style="color: #4A90E2; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; background-color: #E6F0FA; padding: 15px; border-radius: 10px;">
    Number Guessing Game in C++
</h1>

<h2 style="color: #2C3E50; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">🎯 Objective</h2>
<p style="font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #34495E;">
    The objective of this game is to guess the number selected by the computer, which is a random number between 1 and 100. The player will receive feedback after each guess, indicating whether the guess is too low or too high.
</p>

<h2 style="color: #2C3E50; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">🛠️ Tools</h2>
<ul style="font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #2D3436; list-style-type: circle; padding-left: 20px;">
    <li style="color: #1ABC9C;">C++</li>
</ul>

<h2 style="color: #2C3E50; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">📦 Deliverables</h2>
<ul style="font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #2D3436; list-style-type: square; padding-left: 20px;">
    <li>Source code of the game in a <strong>.cpp</strong> file</li>
    <li>Instructions for running the game</li>
</ul>

<h2 style="color: #2C3E50; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">💡 Game Instructions</h2>
<div style="background-color: #FDF2E9; border-left: 6px solid #E67E22; padding: 15px; margin: 10px 0; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">
    <h3 style="color: #D35400;">How to Play</h3>
    <ul style="padding-left: 20px;">
        <li>The computer will select a random number between 1 and 100.</li>
        <li>Your task is to guess the number. After each guess, the game will tell you whether your guess is too low or too high.</li>
        <li>Keep guessing until you find the correct number.</li>
        <li>Once you guess correctly, the game will display how many attempts it took to guess the correct number.</li>
    </ul>
</div>

<h2 style="color: #2C3E50; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">🧠 Features</h2>
<ul style="font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #2D3436; list-style-type: disc; padding-left: 20px;">
    <li>Random number generation between 1 and 100</li>
    <li>Feedback on each guess (Too high, Too low, or Correct)</li>
    <li>Attempt counter to track the number of guesses made</li>
</ul>

<h2 style="color: #2C3E50; font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;">⚙️ How to Run</h2>
<ul style="font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #2D3436; list-style-type: circle; padding-left: 20px;">
    <li>Copy and paste the code into a <strong>.cpp</strong> file (e.g., <strong>guessing_game.cpp</strong>).</li>
    <li>Compile the code using a C++ compiler: <code style="background-color: #ECF0F1; padding: 3px 6px; border-radius: 5px;">g++ guessing_game.cpp -o guessing_game</code></li>
    <li>Run the program: <code style="background-color: #ECF0F1; padding: 3px 6px; border-radius: 5px;">./guessing_game</code></li>
</ul>
